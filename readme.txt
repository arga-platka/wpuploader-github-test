A minimal dummy plugin used to exercise WPUploader's GitHub import end to end.

== Description ==

This plugin intentionally does nothing useful. It exists so that WPUploader's
GitHub import, Plugin Check, readme handling, and release review can be tested
against a real repository.

The readme text here is the version that lives **in the repository**. Editing
the readme inside WPUploader should surface a difference against this text.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate it from the Plugins screen.

== Frequently Asked Questions ==

= Does this plugin do anything? =

No. That is precisely the point.
